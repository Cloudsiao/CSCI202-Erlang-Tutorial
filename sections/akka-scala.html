1. Introduction to Akka and Scala

Scala is a statically typed programming language that combines functional and object-oriented programming.

Akka is a framework for building concurrent and distributed applications using Scala and Java. It provides actor-based programming features while running on the Java Virtual Machine (JVM).

Similar to Erlang, Akka uses the actor model, where actors maintain their own state and communicate through asynchronous message passing.

2. Actor-Based Concurrency

Both Erlang and Akka support actor-based concurrency. Each actor has its own logical state and mailbox, and processes incoming messages one at a time. Different actors can execute concurrently.

In Erlang, actors are implemented as lightweight BEAM processes. In Akka, actors are managed by the Akka framework, which schedules their execution using the JVM's underlying threads.

Example: Sending a Message

Erlang

Worker = spawn(fun() ->
    receive
        hello ->
            io:format("Hello from Erlang!~n")
    end
end),

Worker ! hello.

Output:

Hello from Erlang!

The spawn function creates a lightweight process. The ! operator sends a message to that process, and receive handles the incoming message.

Scala with Akka Typed

import akka.actor.typed.ActorSystem
import akka.actor.typed.scaladsl.Behaviors

val worker = Behaviors.receiveMessage[String] {
    case "hello" =>
        println("Hello from Akka!")
        Behaviors.same
}

val system = ActorSystem(worker, "WorkerSystem")

system ! "hello"

Output:

Hello from Akka!

ActorSystem creates the actor system with the specified behavior. The ! operator sends a message to the actor. The behavior handles the message and returns Behaviors.same to continue using the same behavior.

Key Difference: Erlang provides lightweight processes directly through BEAM. Akka provides actor-based concurrency as a framework that runs on the JVM.
